- `tests/ice.test.mjs`：17 项测试。README 仅新增一行数据源。已有 `loadCoreContext()`、`staticMetrics()` 和 `point_facts` 已实际接通这些数据。

## 方向核实

每种变换使用 **5,038,164** 个有效 Tmax 像元中心，比较原始温度 `Tmax < 110 K` 与 120 m PSR 位图。以交并比（IoU）选方向，避免大量暖区 / 非 PSR 像元主导得分；完整混淆矩阵见 `ice.json`。

| 源坐标 → 地图坐标（乘 1737.4 km） | 一致率 | IoU |
|---|---:|---:|
| **x, y** | **95.4998%** | **0.441531** |
| y, x | 90.3896% | 0.094499 |
| −x, y | 89.9210% | 0.070856 |
| −y, −x | 89.8522% | 0.067467 |
| x, −y | 89.6289% | 0.056626 |
| y, −x | 89.5783% | 0.054205 |
| −y, x | 89.5122% | 0.051051 |
| −x, −y | 89.4612% | 0.048633 |

结论：源坐标轴方向与仓库一致；打包时只将升序 y 的行翻转成从 +y 到 −y。胜出方向的一致率高于次优 **5.11 个百分点**，IoU 高出 **0.3470**。从坐标数组得到像元步长 **0.2400359575 km**，像元边界半宽 **304.0055402 km**；查询另裁到 80°S 圆形覆盖。

## 决策、设计差异与局限

- 沿用建议的深度向上取整至厘米、温度四舍五入至 2 K 编码。方向评分始终使用未量化 Tmax。覆盖内 NaN 深度返回 `depthM: null, cls: 'none'`，温度仍可用；覆盖外返回 null。
- `shallow` 目标包含表面稳定像元；默认钻深 1 m。本源全部有限深度小于 0.73 m，因此默认 `shallow` 与 `any` 距离平面相同。保留 stub 已声明的 `deep` 分类，以兼容更深的有限值；本数据不会产生该分类。
- 查询目标和距离包统一要求 **8 连通、≥ 0.5 km² 地面面积**；面积按极射赤面投影比例修正。表面类别保留 754 个斑块，默认浅层 / any 各保留 3,138 个。`at()` 仍报告小斑块上的单像元结果。自定义钻深按量化后深度筛选，临界厘米内可能保守排除像元。
- 距离的 0 仅表示合格斑块像元占该格超过一半；其余距离到最近像元中心，四舍五入且至少 1 km。采用 **254 km 封顶、255 专作无数据 / 无合格目标**，区别于建议中让 255 同时表示封顶值的编码，避免歧义。`nearest()` 返回未取整的像元中心距离。
- 依 D brief 交付两个单点栅格与两个三平面距离包；未另建 DESIGN §10 早期设想的格内面积占比包。斑块面积在查询时按需计算、缓存；自定义钻深仅缓存最近一种。
- 构建日期固定为本次数据包日期 `2026-11-15`，无随机数或输出中的运行时钟；相同输入可重建相同字节，文件仅在内容改变时写入。
- netCDF 读取器针对固定大小的 CDF-1；记录变量和其他格式明确拒绝。合成测试直接在内存写完整文件头与数据（含 NaN），不额外创建磁盘测试文件。
- 这是 **thermally stable, possible ice**，不证明冰的存在、含量或成分。NaN 不排除更深处稳定；斑块在覆盖边界截断；距离不代表巡视器可达性。用途为首轮筛查，不是认证级着陆分析。
